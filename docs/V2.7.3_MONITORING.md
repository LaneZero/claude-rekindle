# ClaudeRekindle v2.7.3 Beta 1

## Behavior

1. A MutationObserver with debounce inspects Claude warning banners shortly after they change.
2. A user-selected 1/2/5/10/15-minute timer provides fallback DOM checks.
3. When `This response ended early.` is present with an enabled Continue button, existing scoped button selection and cross-tab claims apply immediately.
4. Optional **Safe page reload** is disabled by default. If enabled, the extension only reloads after a hard quota reset time is due, if the quota warning is still visible, no Continue button exists, no resume verification is underway, and there is no detectable unsent draft. It attempts at most three times within one tab session.
5. A page reload cannot be guaranteed harmless to ongoing server tasks, file uploads, or application memory. Do not enable Safe reload during important sessions.

## Test plan on Firefox and Chrome

- Open the popup, go to **Settings**, select 2 min and Save. Reopen and confirm it persists.
- Trigger or simulate an ended-early banner and verify the enabled Continue button is clicked without waiting 2 minutes.
- Verify quota `You are out of free messages until 10:00 PM` has no early automatic click.
- With Safe reload off, verify there are no automatic page navigation reloads.
- With Safe reload on, check that unsent input and pre-reset times block reload, and that the attempt cap is respected.
- Verify old extension/user-script versions are disabled, and that no duplicate Continue occurs.

**Manual in-browser testing and mobile OS background behavior remain unverified.**
