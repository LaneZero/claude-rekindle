# v2.7.1 Beta 1 — Browser popup width hotfix

## Root cause
The v2.7 mobile popup CSS used `max-width: 100vw` and `min-width: 0` on the popup body. Browser-action popups compute their viewport from their content; in Firefox, that combination can cause circular sizing and a window only a few dozen pixels wide.

## Fix
- Set explicit intrinsic `370px` width on HTML and BODY.
- Remove viewport-based maximum width and the zero minimum width from the popup root.
- Keep touch targets 44px high and prevent letter-by-letter tab wrapping.
- Keep all v2.7 features and permission behavior unchanged.

- Test Chrome desktop similarly
- Test Firefox Android: available width, scroll behavior, keyboard and interaction; this remains unverified until tested on a real device
