# ClaudeRekindle v2.6.0 Beta 1

## UI and brand
- Resized original supplied icon into conventional extension icon assets.
- Redesigned the Chrome / Firefox popup with Overview, Activity, About and Support views.
- Included repository link and verified exact user-supplied donation addresses in the Support view.
- Added accessibility labels, focus styling and reduced-motion support.
- Kept the existing detection engine and its stored history unchanged.

## Known limitations
- Firefox Android requires real-device usability testing.
- Browser popup must be tested in actual Firefox and Chrome; source/static tests do not prove UI behavior.
- Tampermonkey's floating UI is not yet redesigned.
- No external payment integration. Addresses are copy-only.
