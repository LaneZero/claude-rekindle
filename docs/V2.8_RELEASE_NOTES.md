# ClaudeRekindle v2.8.0 Stable — Release notes

First v2.8 Stable source release of ClaudeRekindle by LaneZero.

## Changes since early betas

- Detect visible Claude pause and free-message quota banners, including hidden accessibility-link text and date-qualified reset notices.
- Resume only eligible paused/early-ended responses using a currently enabled **Continue** control scoped to an identified warning banner.
- Show local reset countdown and notify the user when the **announced** time arrives. Arrival is **not proof** usage is available again.
- Guard automatic page refresh against unsafe conditions. Support monitoring controls, local activity status, and a responsive popup.
- Share detection and content code with the Tampermonkey build, with different execution limits.
- Preserve the original project icon, About and Support panels, and narrow host scope to `https://claude.ai/*`.
- Harden clock boundary handling, notification opt-out, cross-tab claim processing, and release packaging.

## Support and limitations

Chrome/Chromium and Firefox Desktop source distributions are provided for local installation and testing. Firefox Android and Tampermonkey are **experimental/legacy** targets with best-effort behavior. Background notifications do not run reliably while the browser is fully closed or suspended. Only browser-store signing can produce approved store distributions.

No quota bypass, automatic prompt submission, or calls to private Claude APIs. Claude is a third-party service and UI changes may affect detection.

## Integrity and provenance

Verify archives with `SHA256SUMS.txt`. GitHub release, tag, and store submission are manual steps and have not been performed by this package.
