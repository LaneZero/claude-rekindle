# ClaudeRekindle 2.6.1 Beta 1 — Show panel hotfix

## Fixed
- **Show page panel** now locates an existing Claude tab even when the popup was opened from another site.
- It activates that tab, waits briefly for the content script, and closes the toolbar popup only after the page confirms visibility.
- If no Claude tab exists it opens `https://claude.ai/new` before trying the panel.
- An actionable error appears in the popup if the content script is unavailable.
- The in-page panel is mounted under the document root and its display has a scoped important override, reducing interference from Claude styling.
- The Tampermonkey menu command uses the same enhanced in-page visibility logic.

## Manual checks
1. Load the unpacked extension and refresh `https://claude.ai`. Click **Show page panel**. Expected: popup closes and page panel appears.
2. While viewing an unrelated site, click **Show page panel**. Expected: switch to the existing Claude tab and show panel.
3. Close all Claude tabs, then click **Show page panel**. Expected: open Claude and show the panel after load.
4. Close the in-page panel with ×. Expected: monitoring continues and Show can reopen it.
5. Firefox and Chrome both require live browser testing, including Firefox Android.

No quota bypass is implemented. No cookies or conversation text are read by the popup.
