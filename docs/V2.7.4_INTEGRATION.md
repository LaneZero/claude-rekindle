# ClaudeRekindle v2.7.4-beta.1: integration and stability

## Changes

- Tampermonkey is generated from the **same** `src/core/detection.js` and `src/extension/content.js` as Firefox and Chrome. Do not edit `src/userscript.user.js` directly.
- The generator includes the userscript-specific settings menu and disables extension-only messaging.
- Ignore mutations caused by ClaudeRekindle's floating panel; only Claude DOM changes cause immediate checks.
- Keep full-page Safe Reload opt-in and off by default. A reload can still interrupt ongoing Claude activity: avoid enabling it for long-running tasks.
- Preserve existing storage keys and the existing browser popup About, Support and GitHub details.

## Scope / QA limits

- Browser extension multiple-tab coordination uses browser background storage. Tampermonkey has no equivalent cross-tab lock in this version and should not run simultaneously with the extension.
- No real browser/mobile end-to-end test has been confirmed on the user's device.
- A banner clearing after clicking Continue is not proof the model has finished its answer.

## Local verification

```powershell
npm run check
npm run pack
```

## Git commands

```powershell
git switch integration/v2.7.3
git pull --ff-only origin integration/v2.7.3
git switch -c feature/shared-userscript-v2.7.4
npm run check
git add .
git diff --cached --check
git commit -m "refactor: share detection engine and prevent panel observer loops"
git push -u origin feature/shared-userscript-v2.7.4
```

The user must first confirm that `integration/v2.7.3` exists on the remote; if not, integrate v2.7.3 first.
