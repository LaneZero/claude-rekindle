# ClaudeRekindle v2.7.0-beta.1 — Mobile UX hardening

- Responsive popup layout with 44px touch targets, no forced 320px minimum width, and narrow-screen fallback.
- Show page panel ignores unsupported window-focus operations on Firefox Android.
- Read status from an existing Claude chat when a non-Claude tab is active, without changing tab selection.
- Open Claude and Refresh status controls are available without an active Claude tab.
- The full feature set, local-only history, privacy notices, brand icons, GitHub and donation details are preserved.

## Test boundaries

`npm run check` validates unit tests and build. It does **not** verify background operation on Android; the operating system may suspend Firefox and content scripts. Physical device QA remains required.

## Manual QA

1. Firefox desktop: open a non-Claude tab, open Popup; it should report the existing Claude chat if present.
2. Close all Claude tabs, open Popup; Open Claude and Show page panel should remain usable.
3. Android Firefox (development installation): check 320px viewport, all tabs, scrolling wallets and touch targets.
4. Android: Show page panel should succeed even if browser.windows.update is missing or throws.
5. Re-test paused/ended-early banner, reminders, and duplicate protection on a real Claude session.
