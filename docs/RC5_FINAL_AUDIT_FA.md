# گزارش ممیزی پیش از انتشار ClaudeRekindle v2.8.0 RC5

تاریخ: ۵ نوامبر ۲۰۲۶  
دامنه: سورس RC4، موتور Regex/DOM مشترک، Content Script، Background، Popup، نسخه Userscript، Manifest، بسته‌بندی و اسناد.

## اصلاحات اعمال‌شده در RC5

1. **اشتباه زمان‌بندی فردا:** بنر ساعت‌محور قدیمی که موعد آن در همان شب گذشته است، دیگر به‌شکل خودکار یک روز جلو نمی‌افتد. برای گذر نیمه‌شب، انتقال روز فقط با شواهد زمانی انجام می‌شود. محدودیت ذاتی پیام‌های بدون تاریخ همچنان باقی است؛ زمان قبلی ذخیره‌شده به رفع ابهام کمک می‌کند.
2. **Selector مربوط به Continue:** شناسایی همچنان به `[data-testid="message-warning"]` محدود است، ولی `role="status"` اختیاری شده تا تغییر جزئی DOM موجب توقف تشخیص نشود. هیچ کلیک روی Continue عمومی یا Upgrade انجام نمی‌شود.
3. **تفکیک وضعیت:** حذف بنر پس از کلیک، دیگر به‌تنهایی باعث resolve شدن زمان بازنشانی نمی‌شود؛ این تغییر اثبات آزاد شدن سهمیه نیست.
4. **تفکیک سابقه زمانی:** زمان ذخیره‌شده برای بنر سراسری Composer از موعد اختصاصی گفتگو جداگانه به پارسر داده می‌شود.
5. **رعایت Disable:** غیرفعال کردن مانیتورینگ، اعلان‌های زمان‌بندی‌شده را نیز سرکوب می‌کند. اعلان‌های سرکوب‌شده بعداً یک‌باره پخش نمی‌شوند.
6. **بسته‌بندی سورس:** حذف افزوده فایل‌های خصوصی یا خروجی تصادفی مانند ZIP، key، pem و پوشه‌های build/release از آرشیو سورس.
7. **کنترل رگرسیون:** تست‌های تازه برای پیام‌های سهمیه، فرمت‌های تاریخی، متن مخفی لینک، هشدار advisory، سناریوهای midnight، Selector ایمن و کنترل اعلان اضافه شده‌اند.

## موارد بررسی‌شده

| بخش | نتیجه |
|---|---|
| پیام `You are out of free messages until 10:20 PM` | پوشش در تست خودکار |
| بنر لینک‌دار با `(opens in new tab)` مخفی | پوشش در تست خودکار و رفع پیشین RC4 |
| `tomorrow at` و `Nov 5 at` | پوشش در تست خودکار |
| هشدارهای درصدی `Over 95% ... Resets at` | طبقه‌بندی جدا، بدون کلیک Continue |
| `Paused when your free usage ran out` | تشخیص فقط در بنر هشدار |
| `Paused: Your free usage returns ...` | تشخیص زمان + توقف |
| `This response ended early` | تشخیص جدا از محدودیت سهمیه |
| `Upgrade` و دکمه عمومی Continue | بدون کلیک خودکار |
| تاریخ نامعتبر و زمان 13:70 PM | رد شدن در پارسر |
| ذخیره/هماهنگی اعلان چند تب | تست‌های موجود و جدید |
| تنظیم Disable و اعلان موعد | تست جدید |
| آیکن، مجوزها، ترتیب بارگذاری Core و نسخه‌ها | Release Preflight |

## مواردی که هنوز مانع اعلام Stable هستند

- تست Chromium DOM در این محیط به دلیل **Timeout** کامل نشد؛ نباید به عنوان Pass تلقی شود.
- نسخه جدید RC5 هنوز در Chrome و Firefox Desktop و Firefox Android **روی دستگاه واقعی آزمایش نشده** است. تأیید قبلی کاربر مربوط به نسخه‌های پیشین است.
- اعلان‌ها هنگام بسته‌بودن کامل مرورگر یا محدودیت اعلان در موبایل تضمین‌شده نیستند.
- فرمت‌های واقعی Claude خارج از فیکسچرهای موجود (تغییر زبان، متن جدید، جابه‌جایی کامل ساختار DOM) هنوز نیازمند مشاهده و اضافه شدن به ماتریس تست هستند.
- آزمون ورود/خروج، تب‌های متعدد، مجوز اعلان ردشده، خاموش/روشن کردن افزونه و بازگشایی مرورگر در RC5 باید دستی ثبت شوند.
- پیش از انتشار فروشگاهی، بازبینی حقوقی/سیاست‌های فروشگاه و بسته‌های امضاشده لازم است.

**تصمیم انتشار:** مناسب برای **GitHub Pre-release / RC5 QA**؛ هنوز **No-Go برای Stable** تا گذراندن آزمون‌های بالا.
